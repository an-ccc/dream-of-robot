認識我

科技學習入門清單

2026-10-21

小孩學科技的清單（依年齡）。點選項目名稱就能直接連到網站，教具連到台灣的購買頁面。

🧒 學齡前～小二（4–8 歲）：用玩的建立概念

  • 不插電程式：用卡片、桌遊和走格子遊戲學「順序」與「指令」，例如 Robot Turtles購買、Botley 程式機器人購買
  • ScratchJr（免費 App）：拖拉積木，讓角色動起來
  • Bee-Bot購買、Matatalab 瑪塔機器人購買：可以實際操作的程式小機器人
  • 積木與樂高 Duplo購買：練習空間感和動手做
  • 數位素養：知道螢幕時間有限，也知道不能隨便點連結

👦 小三～小六（8–12 歲）：開始動手做作品

  • Scratch（scratch.mit.edu）：做遊戲和動畫，是最推薦的入門工具
  • Code.org：有中文的「一小時玩程式」課程
  • micro:bit：可以寫程式控制 LED 和感測器，台灣很多學校在用 台灣購買
  • LEGO SPIKE / Mindstorms購買：組機器人再寫程式控制
  • Tinkercad：3D 建模入門，也能練電路模擬
  • Minecraft Education：在遊戲裡學程式和邏輯
  • 基本電腦技能：打字、檔案管理、搜尋資料、判斷資訊真假

🧑 國中（12–15 歲）：學真正的程式語言

  • Python：語法簡單，用途廣，最適合當第一個文字程式語言
  • Arduino：寫程式控制電子元件，適合做專題 台灣購買
  • 網頁基礎：HTML / CSS / JavaScript，做一個自己的網頁
  • App Inventor：自己做手機 App
  • AI 入門：用 Teachable Machine 訓練一個小模型，同時學會怎麼正確使用 AI 工具
  • 資訊安全：密碼管理、詐騙辨識、個資保護

🎓 高中（15–18 歲）：深入發展與準備升學

  • APCS 檢定：程式能力檢測，對大學申請有幫助
  • 進階 Python：資料分析、機器學習入門
  • 專題與競賽：資訊奧林匹亞、機器人競賽、科展
  • 開源與 GitHub：在 GitHub Skills 學會版本控制，在 GitHub 累積作品集
  • AI 應用與倫理：了解 AI 怎麼運作、有哪些限制和偏見

✅ 通用原則

  1. 先培養興趣，再談技術：從遊戲和作品開始，不要一開始就背語法
  2. 做出東西比學了多少更重要：每個階段都要有完成的作品
  3. 不插電能力也算科技力：邏輯思考、拆解問題、合作
  4. 數位公民素養從小教：網路禮儀、隱私、媒體識讀
  5. 控制螢幕時間：重點是「創作」，不是只「消費」內容
